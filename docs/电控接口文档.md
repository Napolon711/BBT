# BBT 电控接口（2026-10-31）

本文件替代旧 `sentry_ref/ref_buy/gimbal_fold` 方案。实现对齐 `27BT-UC` 当前 `ros2_libxr`，20261029 裁判协议在 NUC 解码；电控转发原始帧。线结构定义以 `src/ros2_libxr/include/ros2_libxr/referee_2027.hpp` 为准。

## SharedTopic 线格式

`0x5A + len[3,BE] + topic_crc32[4,LE] + timestamp_us[8,BE] + CRC8 + payload + CRC8`。
Payload 为小端，名称参与 CRC32，不能只改名称保持旧载荷。

| 话题 | 方向 | 载荷 |
|---|---|---|
| ref_frame | 电控→NUC | 136 B：bus:u8, seq:u8, len:u16, tick_ms:u32, raw[128]；raw 含完整裁判帧 |
| chassis_state | 电控→NUC | 22 B：vx/vy/wz 三个 float，fold_state:u8, posture:u8, buffer_energy_j:u16, power_w:u16, tick_ms:u32 |
| ahrs_quaternion | 电控→NUC | 16 B：float x/y/z/w，Eigen 顺序 |
| yawmotor_angle | 电控→NUC | float，rad |
| ref_tx | NUC→电控 | 136 B：cmd_id:u16, len:u16, bus:u8, rsv[3], data[128]；data 仅内容段 |
| chassis_data | NUC→电控 | 12 B：float vx/vy/wz，m/s、rad/s；对应 ROS linear.x/linear.y/angular.z，不交换轴 |
| chassis_mode | NUC→电控 | u8：0 RELAX / 1 INDEPENDENT / 2 ROTOR / 3 FOLLOW |
| fold_cmd | NUC→电控 | u8：1 折叠 / 2 展开 |

裁判帧：`0xA5 + data_length[2,LE] + seq + CRC8 + cmd_id[2,LE] + data + CRC16`。data_length 只计内容数据，不包括 cmd_id 或 CRC16。

## 机构和底盘

`chassis_state.fold_state`：0 未知 / 1 折叠中 / 2 已折叠 / 3 展开中 / 4 已展开。必须来自真实反馈并持续刷新，建议至少 10 Hz；超过 1 秒无更新决策视为未知。每次新指令都要求后续到位反馈，禁止收到指令即假报到位。

ROTOR 的目标角速度通过 `chassis_data.wz` 传递，0 必须停转；不新增 `chassis_spin` 串口话题。BBT 适配层随旋转需求切换 ROTOR/INDEPENDENT。桥在 cmd_vel 或 spin 过期时清除对应旧控制，cmd_vel 断流默认 200 ms 下发全零速度；电控还须有独立的掉线保护。

## 裁判输入和小地图点击

电控转发各裁判命令原始帧，不维护另一份 NUC 摘要结构。桥发布 14 元素 `/referee/summary`：

| 下标 | 含义 |
|---|---|
| 0–4 | 比赛进度、HP、HP 上限、17 mm 允许发弹量、金币 |
| 5–7 | 己方前哨 HP、己方前哨阵地控制状态、控制状态有效标记 |
| 8–11 | 阶段剩余秒、源时间戳 ms、己方基地 HP、己方累计控制度 |
| 12–13 | 必需源数据年龄 ms、对方前哨 HP |

同时发布 `rm2027_interfaces` 的 RobotStatus、RobotHP、FieldEvent、SentryInfo 等消息。控制状态按己方视角：0 完全控制 / 1 临时控制 / 2 未控制；3 保留、不能当有效占领状态。

`0x0303` 由桥解析成 Float64 `[type,param,seq,x,y]`。地图点击 type=4、param=-1，坐标为固定裁判系；机器人头像 type=5。服务器重复内容不会产生新 seq。

## 购买唯一执行通路

决策发布 `rm2027_interfaces/SentryCommand` 到 `/referee/sentry_command`；桥封装 `0x0301` 子内容 `0x0120`，发送者为本机 7/107，接收者为 `0x8080`，经 `ref_tx` 交给电控组帧发送。

累计发弹量、远程买弹次数、远程回血次数由裁判 `0x020D` 回读同步。远程次数一次 +1，重发相同值；未确认不能跳到下个次数。回血请求不指定 HP 数，恢复量按规则执行。确认计数不代表实际到账，还要等待 6 秒效果延迟。复活请求成功后撤销确认位。

电控不再消费 `ref_buy`，也不能另外消费 `/sentry/buy_*` 再执行一次。`/sentry/attack_cmd` 由自瞄侧按 ROS 契约接入，不新增 `sentry_attack` 串口载荷。

## 联调验收

先用本仓库 PTY 测试验证组帧，再在真机核对：SI 速度轴和大小、ROTOR 的正负/零角速度、折叠真实到位及断流、裁判双方映射、购买回执和重复发送、取消导航与速度仲裁。一次物理串口只由一个桥进程打开。
